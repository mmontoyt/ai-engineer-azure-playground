# LLM Systems – Azure Playground

This repository contains a minimal, production-oriented setup for building
LLM-based systems using Azure OpenAI, FastAPI, and LangChain/LangGraph.

## Scope
- Local FastAPI service
- Azure OpenAI integration
- Incremental evolution from simple inference to RAG and agents

## Non-Goals
- No databases
- No blob storage
- No UI
